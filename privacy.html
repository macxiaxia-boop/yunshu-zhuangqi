隐私政策

最后更新:2026-10-16 · 装报价(yunshu-zhuangqi)隐私政策

🛡️ 核心原则:装报价数据本地存储,完全由您自己控制。
  • 项目数据保存在您的本地浏览器(localStorage)
  • 不上传服务器,无云端同步(付费激活仅用于本地激活验证)
  • 可随时导出 ZIP 备份或清除

1. 我们收集的信息

公开免费使用:本服务不收集任何信息。您可以直接打开 app.html 使用所有功能,无需填写任何表单,无需邮箱验证,无需手机号。

付费激活(可选):仅当您主动选择「付钱激活」时,我们会收集:

  • 手机号(用于账号登录 + 激活验证)
  • 密码(用于账号登录,不上传服务器)
  • 工作室 / 公司名称(用于账号标识)
  • 激活码(用于开通企业级功能)

上述信息仅保存在您的本地浏览器(localStorage),不上传服务器。

2. 我们不收集的信息

  • ❌ 您的项目内容(品牌/客户/项目名/报价金额/联系人/地址)
  • ❌ 您的浏览器历史记录
  • ❌ 您的 IP 地址 / 设备型号 / 操作系统版本
  • ❌ 您的地理位置(不调用 navigator.geolocation API)
  • ❌ 任何第三方追踪(无 GA / 百度统计 / 任何 analytics)

3. 第三方服务

本服务部署在 GitHub Pages(pages.github.com),GitHub 可能根据其隐私政策(GitHub Privacy Statement)记录访问日志(IP / User-Agent / 时间戳),但不记录您在应用内的操作。

本服务不使用其他第三方服务:无 CDN / 无 analytics / 无广告 / 无支付 SDK(支付仅微信收款码)。

4. 数据存储

· 公开免费用户:数据保存在您的浏览器 localStorage(key: yunshu-projects / yunshu-clients / yunshu-config),不上传服务器。

· 付费激活用户:同上 + 账号信息(key: yunshu-accounts / yunshu-user / yunshu-codes-used),仍本地存储。

· 您可随时:导出 ZIP 备份 → 清除浏览器数据 → 从备份恢复。

5. Cookie 与 LocalStorage

本服务不使用 Cookie。

使用 localStorage 存储:

  • yunshu-projects:报价项目数据
  • yunshu-clients:客户信息(姓名/地址/手机号)
  • yunshu-config:应用配置(主题色/水印/打印)
  • yunshu-accounts:付费激活账号
  • yunshu-user:当前登录用户
  • yunshu-codes-used:已发放激活码记录

localStorage 是浏览器原生能力,仅本域名(yunshu-zhuangqi.pages.dev)可访问。

6. 数据导出与清除

您对自己的数据有完全控制权:

  • 导出:app.html → 系统设置 → 团队克隆 → 导出 ZIP
  • 导入:app.html → 系统设置 → 团队克隆 → 导入 ZIP
  • 清除:浏览器设置 → 清除本站 Cookie 与 localStorage(将永久删除本地数据,无法恢复)

7. 数据共享

本服务不与任何第三方共享您的数据。无 analytics、无广告 SDK、无数据出售/出租。

唯一例外:如法律强制要求(如法院传票),我们可能根据 GitHub Pages 访问日志配合调查,但应用内数据在我们服务器上不存在,无法提供。

8. 未成年人保护

本服务面向装企(企业用户),不针对未成年人。如您是未成年人(<18 岁),请在监护人同意下使用本服务。

9. 您的权利

您对自己的数据拥有以下权利:

  • 知情权:本隐私政策已说明所有数据行为
  • 访问权:您的所有数据均在本地浏览器,可随时查看
  • 修改权:客户/项目信息可在 app.html 直接修改
  • 删除权:浏览器清除数据即可永久删除
  • 导出权:导出 ZIP 即获得完整数据副本
  • 可携权:ZIP 文件是 JSON 格式,可读可解析

10. 隐私政策变更

· 本政策可能因服务更新而变更,变更会通过 GitHub Release Notes 通知。

· 重大变更(如数据存储方式变更)会提前 30 天通知。
